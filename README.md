# biz.dfch.BpmnMcp

A Model Context Protocol (MCP) server for agent-and-human BPMN 2.0
process modeling: create, change, import, export, validate, and parse
BPMN diagrams. Free and Open Source Software, runs entirely locally /
on-premises.

See [`AGENTS.md`](./AGENTS.md) for the full specification pointers,
the chosen architecture, and the current implementation scope.
